# Execution engine

Kotlin common reducer used by the Android prototype and by JVM tests. The browser uses the separate TypeScript engine in `packages/engine-ts`. ADR-0002 records why the Kotlin/JS library is not the React runtime. The reducer is pure and takes virtual time as an input. Android audio, persistence, and UI stay outside this module. See `docs/architecture/execution.md` and `examples/expected/`.

Compiler input may be a standalone immutable Training Template revision OR Template revision plus validated Program membership override and version policy. Compiler never depends on organization to execute a workout. Produce effective plan with source-to-derived set instance IDs; fail closed if set-pattern repetition/selection cannot preserve valid composite order. Historical Workout Sessions capture exact effective plan and organizational provenance. Auto-upgrade incompatible overrides forbidden; explicit session-to-future promotion is separate from runtime. Read `docs/architecture/seasons-programs-and-promotion.md`.
