# M2–M5 detailed release checklist

## M2 — Execution and simulator

Full sets, intervals, long holds, phase variants, per-set equipment/resistance, alternating exercises and manual-rep stopwatch with auto-next or manual next; insert/reorder mid-session; strict previous occurrence-specific performance; completion and quality/journal logging. Audio/TTS/language/ducking/calls/Bluetooth custom policies, lock/background notification controls, planned vs actual telemetry. Web simulator 1×/2×/5×/10×, step/jump, preview, audio tests, invalid-transition validation. Accept on phone, web and shared fixtures.

## M3 — Authoring/media and import

Visual editor and YAML direct edit, full schemas, drag/drop and undo/redo, archive/compare, different exercise family variations, multilingual aliases and media; location equipment profiles. Optional AI PDF import with BYOK provider selector/usage, manual extraction path, provenance, uncertainty, explicit review/apply, links to originals stored privately. Malicious/ambiguous PDF content cannot become executable commands. Compare draft vs active template. Approve every external provider and billable item.

## M4 — Historical conversion and derived journal

Assisted legacy Google Sheets import with source references and ambiguous fields preserved, dry-run, review/sign-off. Annual Sheets output with monthly tabs, projected compact row-by-exercise layout, same-day sessions, subjective quality/journal fields, source links, protected third-party feedback, duplicate-safe coordinated queue and rebuild. Independent versioned backups outside active directory with selective preview/restore. Basic history comparison and analytics foundation.

## M5 — Release hardening/cutover

Complete all P0s; security and GDPR-aware lifecycle, auth and storage account separation, compatibility matrix Android 12+, latest Android platform, long-session background/locked checks, real battery and responsiveness review, accessibility/screen reader tests; online/offline, network fail/retry, corrupt YAML, cloud permission revocation, conflict preservation, backup/restore and process death. GitHub CI/CD, signed APK and path to Play closed testing, staging/prod, user-approved managed hosting ≤€10/mo target excluding AI, EU preference. Short parallel usage, journal comparison, migration approval, old journal read-only archive.
