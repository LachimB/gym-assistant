## Mandatory unfinished-session recovery

These criteria are mandatory for M1. They are not M0 acceptance gates. The 2026-11-01 Pixel 10a observation showed a clean restart after process termination and loss of the unfinished execution position. That limitation is accepted for M0 only.

M1 must:

- Write automatic workout checkpoints after execution transitions and user actions.
- Recover the last reliably recorded execution position.
- Show a resume/discard prompt after application restart.
- Preserve completed and partially completed performance records.
- Record no fabricated exercise progress during unobserved periods.
- Test process termination, restart, recovery, and subsequent synchronization.
