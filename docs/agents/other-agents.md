# Codex, Claude Code and other agents

They must begin by reading `AGENTS.md`, `docs/product/requirements.md`, `docs/architecture/open-questions.md`, current milestone and `docs/agents/HANDOFF.md`. Do not duplicate requirements in tool-specific instructions. When moving between agents, update HANDOFF with branch, tests, known failures, scope and approvals; do not assume context transfer. A model-specific tool may create local code, but it must not take cloud/GitHub/financial actions beyond the approved scope.
